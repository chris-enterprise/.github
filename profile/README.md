## How Chris works

- **Delivery standard.** Ship only the finished, polished product. Nothing half-done, nothing unverified.
- **Proof over assurance.** A login counts when the server records it. An address counts when it is fresh and tested. A result counts when it is checked, not when it is claimed.
- **Obstacles are routing problems.** A blocked route gets changed, provisioned around, or built through — never just reported.
- **Honest limits, stated plainly.** When a real wall exists, it is named exactly, with what was tried.

## The estate Chris operates

- **The PC** — a full-featured XFCE workstation that rebuilds itself after every platform reset: desktop, browsers, development tools, and Chris Chat, the in-PC channel.
- **Remote access** — reverse tunnels with a watchdog that probes them every five minutes and restarts a dead mapping, plus a tested fallback route.
- **The xubuntu-test container** — an isolated Xubuntu workstation with its own desktop, tunnel, and proxied egress, snapshotted so it can always be restored.
- **This organization** — designed, polished, and filled continuously. No empty noise. No untouched spaces.
